Exponential ITI Jitter Distribution & HRF Covariance Efficiency

Random exponential ITIs break regressor collinearity

Why Exponential ITI Jittering Matters

Because the BOLD HRF takes ~20 seconds to return to baseline, rapid event-related designs with fixed ITIs cause heavy overlapping of responses.

Design Efficiency Equation:
$Efficiency(c, X) = \frac{1}{c^T (X^T X)^{-1} c}$

By sampling ITIs from an exponential distribution ($p(t) = \lambda e^{-\lambda t}$), trial onset times become un-correlated. This minimizes the variance $(X^T X)^{-1}$, allowing independent estimation of Face and Object HRFs.

fMRI Electrophysiology & Canonical HRF Principles

1. Exact Causal Double-Gamma HRF Formula

The canonical SPM Hemodynamic Response Function $h(t)$ is modeled as a difference of two Gamma functions:

h(t) = A * [ (t^a1 * e^(-t/b1) / Γ(a1)*b1^a1) - c * (t^a2 * e^(-t/b2) / Γ(a2)*b2^a2) ] for t >= 0
h(t) = 0 for t < 0

Where $a_1=6, b_1=1$ (response peak at 5–6s) and $a_2=16, b_2=1, c=0.16$ (post-stimulus undershoot at 10–14s). Crucially, $h(t) \equiv 0$ for all $t < 0$, guaranteeing zero response leak into pre-stimulus baseline periods.

2. General Linear Model (GLM)

The BOLD time series $Y$ is modeled as a linear combination of predicted HRF regressors $X$ plus noise:
Y = X₁β₁ + X₂β₂ + ... + Xₙβₙ + ε Beta weights ($\beta$) reflect percentage signal change ($\Delta S/S$) elicited by each task condition.

3. Jittered Exponential ITIs

Sampling ITIs from an exponential distribution ensures high variance in stimulus timing, preventing the HRF responses of consecutive trials from blending into a steady DC offset.
